3. Meta title under 60 characters, Chicago Title Case, hyphen separator. Meta description 130 to 160 characters with a CTA. Excerpt: two sentences plus CTA plus one emoji.

5. No FAQPage schema (Mike, 21 Oct 2026): FAQs are visible content only, five per service page; HowTo is the only schema added on WordPress.
6. Metadata and JSON-LD only when asked, as separate labelled outputs. Add a Sources list when external facts were used. Never write credentials into files or chat.
7. Leave 2018 to 2023 era draft posts untouched.
